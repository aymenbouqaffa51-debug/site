02 Cells

Five cells.

Four technical cells — web, reverse, pwn and cloud — plus pentesting & bug bounty. Ottalhao coordinates the technical four; Ztafjout leads the offensive engagements. Members pick one during onboarding.

01Ottalhao

Web

Injection, authentication flaws, SSRF, template injection and deserialisation — OWASP patterns against real stacks.

02Ottalhao

Reverse

Static and dynamic analysis with Ghidra, x64dbg and Frida. Stripped binaries, custom VMs, packed samples.

03Ottalhao

Pwn

Stack and heap fundamentals, ROP, format strings, mitigations and how to bypass them.

04Ottalhao

Cloud

Cloud attack surface, IAM misconfiguration, containers, CI/CD and the metadata paths people forget.

05Ztafjout

Pentesting & Bug Bounty

End-to-end engagements: recon, exploitation, and a report a triager will actually accept.
